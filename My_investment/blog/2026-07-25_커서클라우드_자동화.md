# 네이버 블로그 초안

> 아래 내용을 복사해 네이버 블로그에 붙여 넣으면 됩니다.

---

## 제목

엑셀 열어보지 않아도 됩니다… Cursor Cloud로 만든 내 주식 자동화

---

## 본문

안녕하세요.

저는 요즘 **Cursor Cloud Automation**으로  
매일 주식 포트폴리오 점검을 자동으로 돌리고 있습니다.

핵심만 말하면 이거예요.

> 정해진 시간에 AI 에이전트가 알아서 시세를 갱신하고,  
> 텔레그램으로 요약을 보내준다.

---

### 뭘 자동화했나요?

매일 **오전 10시 · 오후 3시(한국시간)** 에 아래가 돌아갑니다.

1. 내 보유 종목 엑셀 시세·금액 갱신  
2. 전체 포트폴리오 요약  
3. 미국/한국 매수신호 TOP20  
4. 주요 시장 뉴스 요약  
5. 바뀐 파일을 GitHub에 자동 저장  

사람이 할 일은 거의 없습니다.  
텔레그램만 보면 됩니다.

---

### 왜 Cursor Cloud인가요?

예전에는 이런 걸 하려면

- 내 PC가 켜져 있어야 하고  
- 스케줄러를 직접 관리해야 하고  
- 에러 나면 내가 직접 고쳐야 했습니다

지금은 다릅니다.

- Cloud Agent가 원격에서 실행
- 프롬프트에 “이 스크립트 실행해”만 적어두면 됨
- 실패해도 텔레그램으로 에러 알림
- 결과는 커밋까지 자동

즉, **내 노트북이 꺼져 있어도** 리포트가 옵니다.

---

### 실제로 받는 메시지

텔레그램으로 이런 식으로 옵니다.

- 오늘 포트폴리오 총액 / 구성 요약  
- 미국 매수신호 TOP20  
- 한국 매수신호 TOP20  
- 그날 주요 뉴스 요약  

매수신호는 단순 차트만이 아닙니다.  
기술적 신호에 **EPS, PER, PBR, 매출·이익 성장**을 같이 봐서 순위를 매깁니다.

그래서 “기술적 반등만 보이는 종목”과  
“펀더멘털도 괜찮은 종목”을 조금 더 구분할 수 있어요.

---

### 구조는 생각보다 단순합니다

```
Cloud Automation (하루 2번)
   ↓
Python 스크립트 실행
   ↓
엑셀 갱신 + 신호 분석 + 뉴스 정리
   ↓
텔레그램 전송
   ↓
GitHub에 결과 저장
```

어려운 건 “완벽한 AI”가 아닙니다.  
**반복 업무를 AI 에이전트에게 맡기는 것**이 핵심입니다.

---

### 쓰면서 느낀 점

좋은 점
- 매일 같은 점검을 빼먹지 않음
- 출퇴근·회의 중에도 결과 확인 가능
- 관심 종목과 뉴스를 한곳에 모을 수 있음

주의할 점
- 자동화는 “판단”이 아니라 “정리”에 가깝습니다
- 최종 매수·매도는 여전히 사람이 해야 합니다
- 시크릿(텔레그램 토큰 등)은 코드에 넣지 말고 대시보드에 보관해야 합니다

---

### 한 줄로 정리하면

Cursor Cloud Automation은  
**“매일 해야 하지만 매일 하기 싫은 투자 루틴”**을  
가장 빠르게 시스템으로 바꾸는 방법입니다.

저는 지금 이걸로  
엑셀 갱신 → 신호 스캔 → 뉴스 요약 → 텔레그램 리포트  
를 하루 두 번 받고 있습니다.

다음에 기회가 되면  
프롬프트를 어떻게 썼는지,  
매수신호 순위는 어떻게 매기는지도 이어서 정리해 볼게요.

읽어주셔서 감사합니다.

※ 본 글은 개인 자동화 사용기이며, 특정 종목의 매수·매도 권유가 아닙니다.
