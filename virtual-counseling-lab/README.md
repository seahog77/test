# 가상내담자 상담실습실

사이버한국외국어대학교 상담심리학부 학생을 위한 AI 가상내담자 상담 실습 플랫폼입니다.

## 📋 프로젝트 개요

### 목적
- 실제 내담자 없이 상담 기술(관계 형성, 감정 반영, 탐색, 위기 평가)을 안전하게 연습
- 사례개념화와 자기성찰을 통한 상담 역량 강화
- AI 슈퍼비전을 통한 즉각적인 피드백 제공

### 대상 수업
- 개인상담 실습
- 노인상담
- 심리검사 (TCI 결과 해석상담 실습 - 향후 확장 예정)

## 🎯 주요 기능

### 1. 접수면접 기록지
- 내담자 기본 정보 및 주호소 확인
- 실습 목표와 권장 분량 안내

### 2. 실시간 상담 시뮬레이션
- AI 가상내담자와 1:1 상담 실습
- 발화 횟수, 경과 시간 자동 기록
- 3단계 층위 공개 시스템으로 실제 상담과 유사한 경험

### 3. 사례개념화 작성
- 핵심 이슈 파악
- 핵심신념과 감정 추정
- 위기 평가

### 4. AI 슈퍼비전
- 6개 항목 평가 (감정 반영, 개방형 질문, 공감적 이해, 조언 자제, 탐색 깊이, 위기 평가)
- 축어록 기반 구체적 피드백
- 대안 반응 제시
- 내담자 설계서 공개

### 5. LMS 제출
- 전체 내용 일괄 복사
- 성찰지 작성 가이드

## 🚀 시작하기

### 방법 1: 로컬 테스트 (HTML 직접 열기)

1. EC-01.html 파일을 브라우저에서 엽니다.
2. **주의**: 현재 버전은 AI 연결이 시뮬레이션으로 동작합니다. 실제 AI 연결을 위해서는 API 서버 설정이 필요합니다.

### 방법 2: API 서버와 함께 배포 (권장)

실제 AI 내담자와 슈퍼비전 기능을 사용하려면 API 프록시 서버가 필요합니다.

#### 필요한 것
- OpenAI API 키 또는 다른 LLM API 키
- 서버 환경 (Cloudflare Workers, Vercel, AWS Lambda 등)

자세한 내용은 [DEPLOYMENT.md](./DEPLOYMENT.md)를 참조하세요.

## 📖 사례 목록

### EC-01: 김순자 (노인상담)
- **주호소**: 불면, 식욕 저하
- **핵심 이슈**: 사별 후 애도, 죄책감, 수동적 죽음 사고
- **실습 포인트**: 
  - 신체 호소 뒤의 애도·죄책감 탐색
  - 조언·안심시키기 자제
  - 직접적이고 차분한 위기 평가
- **위기 신호**: 있음

### EC-02: 박정호 (노인상담) [구현 예정]
- **주호소**: 분노, 타인 탓
- **핵심 이슈**: 퇴직 후 고립감, 역할 상실
- **실습 포인트**: 
  - 저항 높은 비자발적 내담자와 관계 맺기
  - 분노 밑의 상실감 반영
  - 조언 자제
- **위기 신호**: 없음

## ⚖️ 윤리 원칙

1. **AI 한계 명시**: AI 응답은 실제 내담자 반응을 대신하지 않음
2. **교육 목적**: 모든 사례는 교육용으로 가공한 가상 인물
3. **위기 관리**: 위기 신호는 제한적으로 설정 (간접 신호 1회, 계획·수단 없음, 보호요인 명시)
4. **이중관계 배제**: 사례에 윤리적으로 부적절한 내용 포함하지 않음
5. **슈퍼비전 한계**: AI 피드백은 교수자 슈퍼비전 전 참고용
